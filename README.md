# Atomic Mass Detective Lab 3.0 — Visual Interactive Edition

อัปเกรดจาก 2.0 เพิ่มขั้นตอนนำทาง 4 ขั้น สถานี Atom Builder แสดงก่อน–หลัง พร้อมปุ่มเพิ่มอนุภาค เครื่องชั่งเชิงภาพใน LAB02 ภาพสัดส่วนใน LAB03 ตัวประกอบอะตอมใน LAB04 และการแสดงผลหลังทดลอง พร้อมตรวจสอบว่าห้ามบันทึกผลเก่าหลังเปลี่ยนตัวแปร

## วิธีติดตั้ง
อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไปที่ root ของ GitHub repository แล้วเปิด GitHub Pages จาก branch main /(root) ระบบไม่มี backend และเก็บบันทึกใน localStorage ของแต่ละอุปกรณ์ ผู้เรียนต้องส่งออก JSON เพื่อส่งครู

## ข้อควรทราบ
- แอนิเมชันแสดงการเปลี่ยนแปลงเชิงสัญลักษณ์ ไม่ใช่โครงสร้างอะตอมจริง
- LAB04 แสดงจำนวนอะตอมตามสูตร ไม่ใช่รูปทรงหรือพันธะจริง
- ค่าของไอโซโทปใช้ชุดข้อมูลใน chemistry.mjs; เลขมวลไม่เท่ากับมวลไอโซโทปที่แม่นยำ
- ระบบครูเป็นการตั้งค่าต่อเครื่อง ไม่มีล็อกอินหรือซิงก์ข้อมูลกลาง
- ลดการเคลื่อนไหวได้ด้วยปุ่มตัวเลือก และรองรับ prefers-reduced-motion
- ยังไม่ได้ทำใบงานหรือแผนกิจกรรม ตามลำดับงานที่กำหนด

## การทดสอบ
`node tests.mjs` และ `node --check app.mjs`

# Atomic Mass Detective Lab 2.0

เว็บแอปภาษาไทยสำหรับเคมีเพิ่มเติม ม.4 หัวข้อ **มวลอะตอม มวลอะตอมเฉลี่ย และมวลโมเลกุล** ประกอบด้วย 6 สถานี: Atom Builder, Atomic Mass Scale, Isotope Mystery, Molecule Factory, Unknown Element, Science Challenge

## เปิดใช้งาน / ทดสอบบนเครื่อง

ไฟล์ JavaScript ใช้ ES Modules จึงควรเปิดผ่าน HTTP ไม่ใช่เปิด `index.html` ด้วย `file://`:

```bash
python -m http.server 8000
```

แล้วเปิด `http://localhost:8000` หรือใช้ VS Code Live Server

## เผยแพร่ผ่าน GitHub Pages

1. สร้าง repository ใหม่ เช่น `atomic-mass-detective` บน GitHub
2. อัปโหลดไฟล์ทั้งหมดจากโฟลเดอร์นี้ไปที่ **root** ของ repository (`index.html`, `styles.css`, `app.mjs`, `chemistry.mjs`)
3. เข้า **Settings → Pages → Build and deployment** เลือก **Deploy from a branch**, เลือกสาขา `main` และโฟลเดอร์ `/(root)` จากนั้น Save
4. เมื่อเผยแพร่สำเร็จ URL จะมีรูปแบบ `https://ชื่อบัญชี.github.io/atomic-mass-detective/` (ชื่อจริงขึ้นกับ repository ของคุณ)
5. เปิดบนโทรศัพท์หรือคอมพิวเตอร์ที่มีอินเทอร์เน็ตเพื่อโหลดหน้าเว็บ

## การใช้งาน

- **โหมดภารกิจ:** ต้องกรอก Predict ก่อนดูผลการทดลอง และ Explain ก่อนบันทึก
- **โหมดทดลองอิสระ:** ปรับตัวแปรและบันทึกได้โดยไม่บังคับกรอกข้อความ
- **สมุดบันทึก:** จัดเก็บข้อมูลด้วย localStorage **เฉพาะเบราว์เซอร์เครื่องปัจจุบัน**; ส่งออก CSV / JSON และพิมพ์เป็น PDF ผ่านคำสั่ง Print
- **ระบบครู:** เปิด/ปิดสถานี ตั้งโจทย์ นำเข้าไฟล์ JSON จากนักเรียน และส่งออก CSV รวม
- ไม่มีระบบบัญชีผู้ใช้ ไม่มีฐานข้อมูลกลาง ไม่มีการยืนยันตัวตนของครู การตั้งค่าครูไม่ใช่ระบบควบคุมสิทธิ์ที่ปลอดภัย
- หากนักเรียนส่งออก JSON เพื่อให้ครูนำเข้า ควรตกลงเรื่องการใช้ชื่อ/ข้อมูลส่วนบุคคลก่อน

## ข้อจำกัดทางวิทยาศาสตร์

- LAB 01 ใช้ `p+n` เป็น **เลขมวล** และค่าใกล้เคียงของมวลใน u เท่านั้น **ไม่ใช่มวลไอโซโทปจริง**
- LAB 02 ใช้มวลไอโซโทปที่แยกต่างหากจากเลขมวล; `1 u = 1/12` ของมวล C-12
- LAB 03 ใช้มวลไอโซโทปจริงสำหรับ C และ Cl แต่ **สัดส่วนที่นักเรียนปรับเป็นค่าจำลอง ไม่ใช่ความชุกชุมตามธรรมชาติโดยอัตโนมัติ**
- LAB 04 ใช้มวลอะตอมสัมพัทธ์แบบค่ามาตรฐานโดยประมาณและแยกสารประกอบไอออนิกเป็น “มวลสูตร” ไม่ใช่มวลโมเลกุล
- การแสดงผลอะตอมเป็นภาพสัญลักษณ์ ไม่แสดงวงโคจร/ขนาดจริงหรือความเสถียรของไอโซโทป
- กราฟแท่งแสดงข้อมูลทดลองล่าสุดในสถานีเดียวกัน ค่าแกนตั้งขึ้นอยู่กับประเภทการทดลอง
- ไม่ใช่แอปจากสำนักพิมพ์อักษรเจริญทัศน์ เป็นสื่อเสริมที่สร้างขึ้นใหม่ตามหัวข้อหลัก

## โครงสร้างไฟล์

- `index.html` หน้าเว็บและองค์ประกอบ UI
- `styles.css` ธีมสีและ responsive layout
- `chemistry.mjs` ข้อมูลธาตุ/ไอโซโทป และสูตรคำนวณ
- `app.mjs` การทำงานของสถานี สมุดบันทึก และระบบครู
- `tests.mjs` การตรวจสูตรคำนวณด้วย Node.js

## ทดสอบ

```bash
node --test tests.mjs
```

ข้อมูลมาตรฐานมวลอะตอมเป็นค่าปัดเศษเพื่อการเรียนรู้ และข้อมูลมวลไอโซโทปใช้ค่าตัวอย่างทั่วไปที่ยอมรับได้จากแหล่งอ้างอิงวิทยาศาสตร์ (ทบทวนค่าที่ละเอียดก่อนนำไปทำงานวัดเชิงมาตรวิทยา)
